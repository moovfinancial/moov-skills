# Example Prompts

Integration recipes you can paste directly into your AI coding assistant. Each example describes a real-world scenario and the prompt that produces a complete integration plan.

## Examples

| Example | Description |
|---------|-------------|
| [Rental management](rental-management.md) | Collect rent via ACH, send invoices for variable charges, onboard property managers |
| [Logistics disbursements](logistics-disbursements.md) | Pay truckers via payout links with instant card payouts and ACH fallback |
| [Marketplace payments](marketplace-payments.md) | Two-sided marketplace: collect from buyers, split to sellers, sweep to bank accounts |

## How to use

1. Install the [Moov AI skill](https://docs.moov.io/guides/get-started/ai-skill/) in your IDE
2. Copy the **Prompt** section from any example
3. Paste it into your AI assistant
4. The AI generates a step-by-step integration plan using native Moov features
